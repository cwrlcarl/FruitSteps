# 🍉 FruitSteps
A **2D platformer** where you collect fruits, avoid traps,
and reach the flag to complete each level. The game is
currently in development, featuring one playable level.


## 🎮 Controls
- **Move:** A / D or ← / →
- **Jump:** Spacebar, W, or ↑
- **Mobile:** On-screen controls


## ⌨️ Built with
- **Godot Engine**
- **GDScript**
